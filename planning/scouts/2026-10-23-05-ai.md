Heavy day (10 captions, 2 drafts, 6 questions, 1 weekly): about 69K in / 20K out = $0.30 on Sonnet (1.1 SAR). Today's Llama path costs $0 inside Cloudflare's free quota. Proposed ceilings: $0.50 a day, $5 a month (18.75 SAR, 2.5x expected use).
Enforcement in three layers: (1) Anthropic Console monthly spend limit $5; at the limit the API answers HTTP 400 "You have reached your specified API usage limits" ([rate limits doc](https://platform.claude.com/docs/en/api/rate-limits)); (2) Worker `ai:usage` KV doc in dollars (not call counts), daily + monthly, one KV write per call, fail closed; (3) per-feature `max_tokens` and 32 KB body caps. KV is not atomic: overshoot is at most one in-flight call (cents), fine for one owner.

## 6 · Risks
- **Runaway spend** (bug loop, leaked token): three layers above, owner bearer token + `ALLOWED_ORIGINS`; the Console limit is the backstop; add a Console email alert.
- **Key safety**: `ANTHROPIC_API_KEY` only as a Worker secret (workflow secret step), never in the bundle, never logged; the browser sends only the Scout token; no prompts in logs.
- **API drift**: since 2026-10-21 any `temperature`/`top_p`/`top_k` is a 400 on every model. The Llama code sets `temperature: 0.5`, so do not share that request builder; variety comes from "3 different angles" in the prompt. Sonnet/Haiku 5.x can return `stop_reason: "refusal"`: treat as unavailable and fall back to Llama.
- **Ban risk** (owner rule): AI must not write follow-gates, "comment X to get Y" outside the existing Smart Reply, or invented trends and stats; hashtags are suggestions (Meta publishes no blocked-hashtag list); Instagram's 5-hashtag cap is widely reported but not confirmed by Meta (keep `hashtagMax` 5). AI-label rules I found concern realistic AI media, not captions (unverified). Commenters' text and DMs never go to the API.
- **Wrong numbers**: answer only from the digest; code checks every figure; "I don't have that number" is a valid answer. Trend claims only from feed items with their dates.
- **Arabic quality**: Anthropic's table puts Arabic at 97.2% (Sonnet 4.5) vs 92.5% (Haiku 4.5) of English on MMLU: an old generation, not Hijazi captions. Run a 10-caption A/B with the owner before fixing the default (under $0.20).
- **Free-plan Worker limits**: 10 ms CPU (waiting on `fetch` is free), 50 subrequests (the digest is built client-side, so no KV fan-out), 1,000 KV writes/day (we add about 1 per call). SDK bundle size and startup untested.
- **Terms**: the Worker may use only the API key; subscription logins stay in the local boundary (the repo already forbids proxying them).
- **Evaluation tier**: a new API org may start with lower rate limits; irrelevant at this volume.
