## 2 · What the platforms and reference tools say
**TikTok (Accounts API, inside TikTok API for Business).** TikTok's own portal pages do not render for WebFetch, so the facts below are from secondary sources unless noted.
- Comments exist only here. Display API and Content Posting API have no comment endpoints; the Research API returns comments but only for academic/non-profit researchers; the Marketing API `/comment/*` is ads-only (needs `advertiser_id`; SDK doc: "Get comments for your ads"). No alternative route; TikTok Studio (manual) is the only fallback. [Fixmation](https://fixmation.dev/blog/one-inbox-for-social-comments), [SDK CommentsApi](https://github.com/tiktok/tiktok-business-api-sdk/blob/main/python_sdk/docs/CommentsApi.md)
- Endpoints: `/business/comment/list/`, `/reply/list/`, `/reply/create/` (`business_id`, `video_id`, `comment_id`, `text`; no ad ids), `/hide/`, `/delete/`, `/like/`. Comment fields seen in connectors: comment_id, video_id, user_id, create_time, owner, status, likes, text, replies, username, pinned. [Saras schema](https://help.sarasanalytics.com/tiktok-business/schema-information)
- **Personal accounts:** the Accounts API "covers insights, comment moderation, and publishing for both Business Accounts and Personal Accounts"; Business Messaging is Business-only ([Adeli](https://www.tryadeli.com/blog/tiktok-api-for-business-vs-developers)); our `16-tiktok-personal-toolkit.md` read the same on TikTok's overview page (Oct 4). `/business/get/` carries an `is_business_account` flag, so the API does return non-business accounts. Counter-signal: Metricool lists TikTok comments "only for business accounts" (its own rule, [help](https://help.metricool.com/inbox-manager-how-to-manage-messages-and-comments-from-metricool-s9zze)). Only the real connect proves it.
- Consent-screen scopes seen at [SocialAPI](https://docs.social-api.ai/platforms/tiktok): `comment.list` (read + webhook) and `comment.list.manage` (reply, hide, like, delete).
- Limits: 40 requests/min per account per endpoint, 600/min app-wide at Basic (two sources agree). In-app comments are 150 characters (third-party tables; SocialAPI claims 1,200 via API, unverified).
- Webhook `comment.update` arrives "within five minutes"; HTTPS callback, must answer 200, at-least-once, retries up to 72 h; header `tiktok-signature`; body `client_key, event, create_time, user_openid, content` (JSON string). Our 5-minute poll is as fast, so **no TikTok webhook in v1**. [apis.io](https://apis.io/asyncapis/tiktok-ads/tiktok-ads-webhooks/), [TikTok webhooks](https://developers.tiktok.com/docs/en/webhooks-overview)
- Review: access form required since Mar 20, 2026; a scope-change review is reported at 2-3 business days (first reviews about 2 weeks); reviewers check every scope is used and nothing beyond the stated use case. Submitted Oct 22, so expect an answer between Oct 27 and Nov 5.

**Meta.** Comments: `GET /{media}/comments`, `POST /{comment}/replies`, `POST /{comment}?hide=true`, `DELETE /{comment}`; an app "only for a business I own or manage" needs no review at Standard Access ([comment moderation](https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/comment-moderation), [app review](https://developers.facebook.com/documentation/instagram-platform/app-review)). **Webhooks:** the app must be Live and "Advanced Access is required for `comments` and `live_comments`" ([setup](https://developers.facebook.com/documentation/instagram-platform/webhooks/setup)). App Review wants, per permission, a use-case text, a screencast of the end-to-end flow (login and consent included), step-by-step tester instructions and test credentials; "if Meta can't access the app" the whole submission is rejected. For messages you pick "Automated" or "Live Agent" (a custom inbox answered by a person): our inbox is Live Agent, keyword replies are Automated ([messaging review](https://developers.facebook.com/documentation/business-messaging/instagram-messaging/app-review/apps-for-your-own-business)). Policy: a private reply is one message within 7 days; 24-hour window; automated chats must disclose automation where legally required and Meta recommends it everywhere ([policy](https://developers.facebook.com/documentation/business-messaging/messenger-platform/policy)).

**AI reply tools.** Beacons Beam is an "AI teammate" for strategy and brand deals (drafts brand-deal replies, some items "coming soon"); fan comments and DMs are handled by Smart Reply keyword rules, not AI drafts ([beacons.ai](https://beacons.ai/)). Metricool's Inbox has manual saved replies only and "does not support automatic replies"; no AI reply found. Sprout's "Enhance by AI Assist" suggests reply options and tones with a human approval step ([Sprout](https://sproutsocial.com/features/engagement/)). Suggest, then the human taps Send, is the market norm and puts us ahead of Beacons and Metricool here.

**Claude (price list cached Oct 6; per 1M tokens in/out).** Haiku 5.5 $0.10/$0.50, Sonnet 5.5 $2/$10 (cache read $0.20), Opus 5.5 $4/$20. Estimate per suggestion (about 1,200 in, 450 out including low-effort thinking, 3 Arabic options): Haiku $0.0003, Sonnet $0.007, Opus $0.014. At 20 a day: Haiku $0.2, Sonnet $4, Opus $8 a month; at 100 a day: $1, $21, $41. Prompt caching (512-token minimum, 5-minute life) only pays in bursts: skip on Haiku. API shape: `output_config.effort: "low"`, JSON via `output_config.format`, no `temperature`/prefill (400), handle `stop_reason: "refusal"` (Haiku 5.5 has no server fallback), `max_tokens` about 800, official `@anthropic-ai/sdk` (Workers is a supported runtime).

## 5 · Risks
- **Ban/spam:** identical automated TikTok comments are the likeliest flag: cap 20 an hour, variants, keyword-only, no links, one per comment, pause switch, stop on repeated 4xx. AI text is never auto-sent; the Instagram keyword bots keep Meta's "disclose automation" recommendation open.
- **Scope creep in TikTok review:** "no extra features beyond the stated use case": check that the Oct 22 form mentions automatic replies before G; if not, amend first.
- **Subrequest budget:** F2 must not touch the Instagram tick's 48 of 50; a separate lane costs Instagram one tick in five.
- **Prompt injection and bad advice:** comments are untrusted; the model has no tools and returns strings only; the owner reads every text; no prices, dates, promises or links; abuse, politics, religion and medical comments are flagged "needs you".
- **Privacy:** commenter text goes to a processor; add the privacy line (`public/privacy`), minimise (no ids, last 6 messages); review Saudi PDPL wording.
- **Cost:** shared caps from 05 ($0.50 a day, $5 a month) plus a per-feature daily cap; the Console spend limit is the hard stop.
- **Meta review exposes the real inbox to reviewers** unless a demo account is built (decision 3).
