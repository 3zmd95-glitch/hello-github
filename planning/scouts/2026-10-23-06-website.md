- **Beacons** (our screenshots; [link-in-bio](https://beacons.ai/i/app-pages/link-in-bio), [custom domain help](https://help.beacons.ai/en/articles/5228993)): page = stack of blocks (Header, Links, Contact form, email signup, product, video/music/embeds, affiliate) with sub-page tabs (ours: Home, Amazon gear, AliExpress gear, Blog), draggable, hide per block; media kit at `3zprod.com/mediakit` with live stats, audience bars, "Work with me" form, readiness meter. Its help page gives no DNS values.
- **Platform facts:** Next 16 static export has no Proxy, redirects, headers or Server Actions ([local docs](node_modules/next/dist/docs/01-app/02-guides/static-exports.md)); Next's own i18n guide (`app/[lang]` + `generateStaticParams`) needs no library. Cloudflare Workers Static Assets: static requests free and unlimited, 20,000 files, 25 MiB/file, `run_worker_first` for chosen paths, `_redirects` (2,000 static / 100 dynamic, 200-rewrites ok) ([billing](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/), [limits](https://developers.cloudflare.com/workers/platform/limits/)). Cloudflare Pages: 500 builds/month, an apex domain needs Cloudflare nameservers ([docs](https://developers.cloudflare.com/pages/configuration/custom-domains/)). GitHub Pages: 1 GB, 100 GB/month, "not intended to run your online business" ([limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)). Resend free: 3,000 emails/month, 100/day, 1,000 contacts; Pro $20/mo ([pricing](https://resend.com/pricing)). Turnstile free, unlimited challenges, token single-use 300 s ([plans](https://developers.cloudflare.com/turnstile/plans/), [verify](https://developers.cloudflare.com/turnstile/get-started/server-side-validation/)). TipTap `@tiptap/static-renderer` renders JSON to HTML with no DOM ([docs](https://tiptap.dev/docs/editor/api/utilities/static-renderer)). Google hreflang: reciprocal, absolute URLs, `x-default` ([docs](https://developers.google.com/search/docs/specialty/international/localized-versions)).
- **Search-before-building result:** adopted Next's own i18n pattern (not next-intl: no middleware under export), `@tiptap/static-renderer`, Resend REST, Turnstile. Rejected `desw0lf/resend-worker-cloudflare` and `willin/resend-cloudflare-service-worker` (a contact route is ~60 lines on our Worker's existing fetch/CORS/Cache helpers; licences and upkeep unchecked). Rejected Astro (second framework; owner chose Next).

## 7. Risks
- **Email breaks on the nameserver move** (Hostinger says the DNS zone moves with the nameservers): copy MX/SPF/DKIM/DMARC first, test both directions, keep the Hostinger records saved.
- **Broken links in the wild** (bio, sent DMs, posts, `/mediakit`, `/lut`, `/gear`): inventory first, 301 everything.
- **Platform rules:** no follow gates (email signup only); `/go` redirects only to owner-saved https links, previews never counted; affiliate disclosure line on gear pages.
- **Public POST endpoints** are the new attack surface: Turnstile + honeypot + rate limit + size cap, CORS to 3zprod.com only, separate router from the bearer routes; the media-kit endpoint returns aggregates only.
- **Limits:** Workers Free 100,000 requests/day (only `/go` and `/api` count), 50 subrequests; Resend free 100 emails/day (a broadcast to more than 100 subscribers needs Pro, $20/mo); KV 1,000 writes/day (so clicks and leads go to the Durable Object); Pages 500 builds/month if ever used; Next 16 differs from older versions (read `node_modules/next/dist/docs` before coding).
- **Privacy:** emails and IPs: consent line, unsubscribe link, store a hashed IP, privacy page first (Saudi PDPL not checked).
- **Cost:** about $0 now; Resend Pro $20/mo later; R2 images free tier expected to be enough.
