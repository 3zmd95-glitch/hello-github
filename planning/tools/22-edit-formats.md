## Implementation and limits

- Separate format records preserve an audio title/artist or specific named format, a visual recipe, source examples, dates and provenance. Different songs or visual patterns stay separate even if both use cloning.
- The scanner analyzes bounded indexed source text before generic technique cleanup. Every automatic example must cite a supplied post and exact supporting spans for both the visual pattern and audio/named format. Model-invented links and unsupported claims are rejected. These are candidate leads from search excerpts, which can include unrelated page context; they are not authenticated source captions or verified audio/visual matches.
- Reallocate two of the existing six query slots to open-ended format discovery and a rotating focused query for a previously detected format. Keep existing search spending limits; no additional category scans, budget increases or paid services.
- A repeated label means recent observations from multiple identified accounts in the indexed sample. It does not mean platform-wide popularity or increasing adoption. Failed/partial scans retain old evidence without making it fresh. Useful older leads remain visibly dated.
- The owner-provided Reel is an explicitly reviewed reference with a descriptive name, separate from automated findings. No publication date or recent-creator count is invented.
- Following saves a format snapshot in the existing dashboard store, includes it in export/import, and keeps it visible when a later scan omits it. It is a personal watch list, not a promise of personalized cloud crawling or notifications. The existing shared daily scan revisits detected formats after Worker deployment.
- Live tutorial-search testing found a second issue: the full artist/album/song/visual phrase returned album news, music reviews and unrelated old tutorials. Format searches now use a shorter song+visual query and retain explicit format context while filtering results. Matching requires the audio or named format and specific visual evidence; a tutorial also needs a teaching cue. A useful empty result is shown when indexed text cannot support a match. Ordinary typed and category searches clear this special context.
- The shorter live query `"TRIP BABY" repeating figures edit tutorial` returned one Instagram lead, https://www.instagram.com/p/DaX6-f9ox7D, with an indexed excerpt mentioning repeating figures, freeze frames, masking and TRIP BABY. **Direct source verification did not confirm that pairing**: the creator is **cj.filmed.it**, the displayed date July 4, the audio is **Original audio** (https://www.instagram.com/reels/audio/27298489599815501/), and the caption only discusses making a tutorial. Partial playback showed a DaVinci masking/transform workflow, not a verified same-format sequence. This demonstrates search-excerpt contamination and is recorded as a failed exact-format verification, not a successful discovery. The UI calls such results unverified leads from indexed text. Do not blacklist this one URL and claim the source-quality problem is solved; authenticated post/audio evidence or audiovisual review remains necessary.
